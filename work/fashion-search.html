Fashion visual search

A prototype for finding visually similar products from an uploaded image, with recommendations based on search history and recent product launches.

Explore the source

This page describes the public implementation. No measured retrieval-quality, latency, or user-study results are reported here. A clean-checkout runtime demonstration remains to be verified.

How the pipeline works

  1. FashionCLIP produces an embedding for each catalog image and the query image.
  2. A FAISS L2 index retrieves image neighbors, mapped back to product metadata.
  3. A Streamlit interface displays results. TF-IDF similarity on descriptions provides a history-based recommendation heuristic.
  4. A separate filter selects recent products with matching brand or description terms. This is recent-launch filtering, without measured popularity data.

Decisions to evaluate

The current implementation uses raw image features and L2 distance. I want to compare that choice with normalized embeddings on a fixed set of labeled queries, while checking product duplicates and invalid neighbors.

Product-level relevance matters more than returning several images of the same item. A useful experiment needs a versioned catalog, a held-out query set, defined relevance labels, and a stable baseline.

Next evidence

  • A clean setup with documented model/data provenance and a small fixture.
  • Tests for empty indexes, invalid neighbors, and duplicate products.
  • Recall@k or ranked-relevance metrics with raw results, latency, and failed queries.
