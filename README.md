# Praneeth Earlagadda's portfolio

An intentionally small personal homepage, hosted on GitHub Pages. Static HTML/CSS and a tiny theme switcher; no build step, analytics, external font download or third-party script dependencies. A hand-built SVG flight path and ASCII paper plane give the page its own detail without an image download. The homepage brings together a short introduction, early projects, an experiment-design note and completed academic work. Personal schedules and application materials live outside this public repository.

Run a static server from this directory to preview, for example `python -m http.server 8777 --bind 127.0.0.1`, then visit `http://127.0.0.1:8777/`. The site uses relative URLs and semantic HTML. Check the homepage, evaluation note, anchor navigation, certificate disclosure and responsive layout before publishing.

Dark is the initial theme. The light/dark text button saves a preference locally and shares it between the homepage and note. If scripts or local storage are unavailable, all content and navigation still work. The decorative plane has a small hover movement, disabled by `prefers-reduced-motion`; there is no continuous animation.
