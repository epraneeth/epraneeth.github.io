# Praneeth Portfolio

A static, dependency-free personal portfolio ready for GitHub Pages.

## Publish it

1. Create a new public repository named `epraneeth.github.io` under the `epraneeth` GitHub account.
2. Upload the contents of this folder (not the folder itself) to the repository root.
3. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Your site will be available at `https://epraneeth.github.io` after GitHub finishes publishing.

## Before publishing

- Replace `hello@praneeth.dev` in `index.html` with your real email address.
- Add a résumé link when you have one.
- Replace the “Currently building” card with links to your first agent projects as you ship them.
